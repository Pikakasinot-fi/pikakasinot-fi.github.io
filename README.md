# pikakasinot-fi.github.io

[Pikakasinot.fi](https://pikakasinot.fi/fi/):n esittelysivu, joka julkaistaan GitHub Pagesissa osoitteessa
<https://pikakasinot-fi.github.io/>.

Sivu on yksi käsin ylläpidettävä `index.html` ilman rakennusvaihetta. Muutos `main`-haaraan julkaistaan automaattisesti.

Fontit Montserrat ja Cabin on lisensoitu SIL Open Font License -lisenssillä (`assets/fonts/OFL-*.txt`).
